1. LinkedList

## Beginner Level (Implementation & Basics)
These help you understand how Linked Lists work.

* Implement a Node class and a LinkedList class in JavaScript.
* Write a function to insert a node at the beginning of a linked list.
* Write a function to insert a node at the end of a linked list.
* Write a function to insert a node at a specific position.
* Write a function to delete a node by value.
* Write a function to delete a node by index.
* Write a function to search for an element in a linked list.
* Write a function to count the total number of nodes.
* Write a function to print all nodes in the linked list.
* Write a function to reverse a linked list (iteratively).

## Intermediate Level (Algorithmic Practice)
These test your understanding of traversal and logic.

* Reverse a linked list recursively.
* Find the middle element of a linked list.
* Find the nth node from the end of the linked list.
* Detect if a linked list has a cycle (Floyd’s cycle detection).
* Remove duplicate nodes from a sorted linked list.
* Remove duplicate nodes from an unsorted linked list.
* Merge two sorted linked lists into one sorted list.
* Check if a linked list is a palindrome.
* Delete the middle node of a linked list.
* Find the intersection point of two linked lists.
